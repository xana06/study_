# Desenho

O âmbito é o definido no documento de restrição de âmbito (`docs/enunciado/`).

- Arquitectura conceptual do sistema, capaz de suportar os requisitos identificados.
- Decomposição em subsistemas, com as respectivas interfaces.
- Modelos comportamentais necessários para descrever o comportamento pretendido.
- Registo de decisões actualizado, incluindo a justificação do que foi deixado de fora
  (`docs/decisoes.md`).

Os diagramas são ficheiros PlantUML (`.puml`).
