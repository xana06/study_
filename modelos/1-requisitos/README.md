# Análise de requisitos

Incide sobre o sistema tal como descrito no Anexo A do enunciado, na sua totalidade.

- Modelo de Domínio com as entidades relevantes.
- Modelo de Use Case: diagrama(s) e especificação de cada use case (uma por ficheiro em `usecases/`,
  a partir de `usecases/_template.md`).
- Questões em aberto, decisões e justificações: `docs/decisoes.md`.

Os diagramas são ficheiros PlantUML (`.puml`).
